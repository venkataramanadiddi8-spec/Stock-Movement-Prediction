# Stock Movement Prediction using Machine Learning

This project predicts stock market movements using historical financial data and Machine Learning models.

### 🚀 Key Features
* Implemented **LSTM (Long Short-Term Memory)** networks to analyze sequential stock price data.
* Built data pipelines for preprocessing, scaling, and engineering technical indicators using **Pandas** and **NumPy**.
* Optimized model accuracy and evaluated performance using metrics like F1-Score and Precision.

### 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** TensorFlow, Keras, Scikit-Learn, Pandas, NumPy, Matplotlib
